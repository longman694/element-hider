# Privacy Policy: Element Hider
Effective Date: 2026-03-21

1. Overview
Element Hider ("the Extension") is a browser extension designed to help users hide unwanted web elements using CSS selectors. We value your privacy and believe in total transparency regarding how data is handled.

2. Data Collection and Usage
No Personal Data: The Extension does not collect, store, or transmit any personally identifiable information (PII).

No Tracking: We do not track your browsing history, IP address, or how you interact with websites.

Local Storage only: The CSS selectors and domain rules you create are stored locally on your device using the browser's storage.local or storage.sync API. This data never leaves your computer and is not accessible by the developer or any third parties.

3. Permissions Justification
To function correctly, the Extension requires the following permissions:

Storage: To save your custom element-hiding rules so they persist across sessions.

ActiveTab / Host Permissions: To inject the necessary CSS into the specific websites where you have requested to hide elements. This is used strictly for UI modification and does not involve reading your private data on those pages.

4. Third-Party Services
The Extension does not communicate with any external servers or third-party analytics services.

5. Changes to This Policy
We may update this Privacy Policy from time to time. Any changes will be reflected by updating the "Effective Date" at the top of this page.

6. Contact
If you have any questions about this Privacy Policy, you can open an issue on the official GitHub repository: https://github.com/longman694/element-hider
